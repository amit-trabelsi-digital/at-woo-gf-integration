# AT - WooCommerce Gravity Forms Integration

תוסף WordPress מתקדם שמחבר בין WooCommerce ל-Gravity Forms עם מערכת ניהול אירועים מלאה ומערכת הרשאות משתמשים מתקדמת.

**מפתח:** Amit Trabelsi - [amit-trabelsi.co.il](https://amit-trabelsi.co.il/)  
**גרסה:** 2.6.0  
**תאריך עדכון:** 13 בנובמבר 2025

## 🎯 תכונות עיקריות

### 🔗 אינטגרציה מלאה
- **שיוך טפסים למוצרים** - הוספת כרטיסייה "Gravity Forms" בעמוד עריכת מוצר
- **יצירת טפסים אוטומטית** - כפתור ליצירת טופס חדש עם שדות בסיסיים
- **סנכרון דו-כיווני** בין מוצרים לטפסים
- **מעקב אוטומטי** אחר הרשמות ומקומות פנויים

### 📅 ניהול אירועים מתקדם
- **סוג מוצר "אירוע"** מיוחד עם שדות ייעודיים:
  - תאריך ושעת התחלה וסיום
  - מיקום (פיזי/וירטואלי/משולב)
  - מספר משתתפים מקסימלי
  - משך זמן האירוע
  - מייל לבירורים
- **מעקב קיבולת** עם סרגל התקדמות ויזואלי
- **ניהול מלאי אוטומטי** המתבסס על מספר הנרשמים
- **טקסונומיות מותאמות** (קהלי יעד, סוגי אירועים)
- **טבלת מוצרים נקיה** - הצגת עמודות חיוניות בלבד (תמונה, שם, מלאי, מחיר, תאריך, סוג אירוע, שפות) לממשק ממוקד וקל לשימוש

### 🔒 סטטוס "מפורסם אך נגיש בלינק ישיר בלבד" - אוניברסלי לכל סוגי התוכן
- **תמיכה מלאה** - עובד על מוצרים, מאמרים, דפים, טפסים וכל post type מותאם אישית
- **גישה ישירה בלבד** - תוכן נגיש דרך קישור ישיר (URL)
- **הסתרה מחיפוש** - לא מופיע בתוצאות חיפוש באתר (כולל חיפוש רגיל וחיפוש Relevanssi)
- **הסתרה מלופים** - לא מופיע בארכיונים, קטגוריות וידג'טים
- **אינטגרציה עם Relevanssi** - תמיכה מובנית למנוע חיפוש Relevanssi
- **ניהול פשוט** - שינוי סטטוס מעמוד עריכת כל סוג תוכן
- **שימושים:**
  - 🛍️ מוצרים פרטיים וקמפיינים ממוקדים
  - 📄 מאמרים ודפי נחיתה לקבוצות ספציפיות
  - 📋 טפסים ותוכן מותאם שדורש שיתוף פרטי
  - 🗃️ תוכן ארכיוני שנגיש בקישור ישיר
- **מדריך מלא:** [HIDDEN-STATUS-GUIDE.md](./docs/HIDDEN-STATUS-GUIDE.md)

### 🎛️ מערכת הרשאות משתמשים

#### 👨‍💻 Administrator (Developer)
- **גישה מלאה** לכל המערכת
- ניהול תוספים ותבניות
- הגדרות מערכת ואבטחה
- ניהול משתמשים והרשאות
- גישה לכל הכלים הטכניים

#### ✍️ Content Manager (מנהל תוכן)
- ניהול מאמרים ודפים
- יצירה ועריכה של אירועים
- צפייה בהרשמות ודוחות
- ניהול טפסי הרשמה
- העלאת תמונות וקבצים
- ייצוא נתוני אירועים
- **ללא גישה:** תוספים, תבניות, הגדרות מערכת

#### 📅 Event Editor (עורך אירועים)
- עריכת אירועים קיימים בלבד
- צפייה בהרשמות
- עדכון פרטי אירועים
- **ללא גישה:** יצירת אירועים חדשים, ניהול טפסים

### 📊 דשבורד הרשמות מתקדם
- **סטטיסטיקות כלליות** עם מגמות וטרנדים
- **חיפוש מתקדם** לפי טקסט, טופס, מוצר ותאריך
- **טבלת הרשמות מאוחדת** מכל הטפסים
- **פעולות מהירות** (עריכה, צפייה, ייצוא)
- **Sidepeek רחב** להצגת פרטי נרשמים
- **רענון דינמי** עם AJAX

### 📧 מערכת התראות ומיילים
- **שליחת עדכונים תקופתיים** (שעתי/יומי/שבועי/חודשי)
- **קבצי CSV מצורפים** עם רשימת נרשמים
- **התראות על אירועים מלאים**
- **אימיילי אישור הרשמה** אוטומטיים

## 🔧 דרישות מערכת

- WordPress 6.0 ומעלה
- WooCommerce 7.0 ומעלה (נבדק עד 8.9)
- Gravity Forms 2.5 ומעלה
- PHP 7.4 ומעלה

## 🚀 התקנה

1. העלה את תיקיית `at-woo-gf-integration` לתיקיית `/wp-content/plugins/`
2. הפעל את התוסף דרך תפריט 'תוספים' בוורדפרס
3. ודא ש-WooCommerce ו-Gravity Forms מותקנים ופעילים
4. התוסף ייצור אוטומטית את התפקידים החדשים

## 👥 ניהול משתמשים

### יצירת משתמש חדש
1. עבור ל**משתמשים > הוסף חדש**
2. מלא את הפרטים הבסיסיים
3. בחר תפקיד:
   - **מנהל תוכן** - לניהול תוכן ואירועים
   - **עורך אירועים** - לעריכת אירועים בלבד
   - **Administrator** - למפתחים בלבד

### שינוי הרשאות משתמש קיים
1. עבור ל**משתמשים > כל המשתמשים**
2. לחץ על **ערוך** ליד המשתמש
3. שנה את התפקיד בתפריט הנפתח
4. שמור שינויים

## 📅 ניהול אירועים

### יצירת אירוע חדש
1. עבור ל**ניהול אירועים > אירוע חדש** (או **מוצרים > הוסף חדש**)
2. בחר **סוג מוצר: אירוע**
3. מלא את פרטי האירוע:
   - כותרת ותיאור
   - מחיר (אם בתשלום)
   - תאריך ושעת התחלה
   - מיקום או קישור זום
   - מספר משתתפים מקסימלי
4. בכרטיסיית **Gravity Forms**:
   - בחר טופס קיים או צור טופס חדש
5. שמור את האירוע

### ניהול הרשמות
1. עבור ל**ניהול אירועים > דשבורד הרשמות**
2. צפה בסטטיסטיקות כלליות
3. השתמש בפילטרים לחיפוש מתקדם
4. לחץ על **נרשמים** לצפייה בפרטי הרשמות
5. לחץ על **ערוך** לעריכת האירוע

### ייצוא נתונים (מנהלי תוכן בלבד)
1. עבור ל**ניהול אירועים > ייצוא נתונים**
2. בחר סוג ייצוא (כל האירועים/אירוע ספציפי/טווח תאריכים)
3. בחר פורמט (CSV/JSON/PDF)
4. לחץ על **ייצא נתונים**

## 🔧 API ו-Hooks

### Actions חדשים
```php
// מופעל לאחר יצירת תפקיד משתמש חדש
do_action( 'at_woo_gf_user_role_created', $role_name, $capabilities );

// מופעל כשמשתמש מקבל הרשאות אירוע
do_action( 'at_woo_gf_event_permissions_granted', $user_id, $permissions );
```

### Filters חדשים
```php
// סינון תפקידי המשתמש הזמינים
$roles = apply_filters( 'at_woo_gf_available_user_roles', $roles );

// התאמת הרשאות לפי משתמש
$capabilities = apply_filters( 'at_woo_gf_user_capabilities', $capabilities, $user_id );
```

## 📋 הוראות שימוש מתקדמות

### למפתחים
```php
// בדיקה אם משתמש יכול לנהל אירועים
if ( current_user_can( 'manage_events' ) ) {
    // הצג אפשרויות ניהול אירועים
}

// בדיקה אם משתמש יכול לייצא נתונים
if ( current_user_can( 'export_event_data' ) ) {
    // הצג כפתור ייצוא
}
```

### התאמה אישית של הרשאות
```php
// הוספת הרשאה מותאמת אישית
add_action( 'init', function() {
    $role = get_role( 'content_manager' );
    if ( $role ) {
        $role->add_cap( 'custom_event_capability' );
    }
});
```
