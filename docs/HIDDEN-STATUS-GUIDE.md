# מדריך: סטטוס "מפורסם אך נגיש בלינק ישיר בלבד"

## 🎯 מה זה?

סטטוס חדש **לכל סוגי התוכן באתר** - מוצרים, מאמרים, דפים וכל post type מותאם אישית:
- ✅ **גישה ישירה** - התוכן נגיש דרך קישור ישיר (URL)
- ❌ **מוסתר מחיפוש** - לא יופיע בתוצאות חיפוש באתר (כולל Relevanssi)
- ❌ **מוסתר מלופים** - לא יופיע בדפי ארכיון, קטגוריות, וידג'טים וכו'
- ✅ **מנוהל בקלות** - ניתן לשנות סטטוס מעמוד עריכת התוכן
- ✅ **אוניברסלי** - עובד על מוצרים, מאמרים, דפים, טפסים וכל post type
- ✅ **תמיכה מלאה ב-Relevanssi** - אינטגרציה מובנית עם מנוע החיפוש Relevanssi

---

## 📋 מתי להשתמש בסטטוס הזה?

### מקרים מתאימים:

#### 🛍️ למוצרים:
1. **מוצרים פרטיים עם קישור ישיר**
   - שיתוף מוצר ספציפי עם קבוצה מסוימת (למשל במייל)
   - מוצר שרוצים להציג רק למי שיודע את הקישור

2. **מוצרים בהכנה**
   - מוצר שמוכן אבל רוצים להציג אותו רק למקרה של צורך
   - בדיקות פנימיות לפני הפצה רחבה

3. **מוצרים עונתיים או זמניים**
   - מוצרים שלא רלוונטיים כרגע אבל צריכים להישאר פעילים
   - מוצרים שנשמרים לשימוש עתידי

4. **לינקים חיצוניים**
   - כשרוצים לשתף קישור למוצר אבל לא להציג אותו באתר
   - עבור קמפיינים שיווקיים ספציפיים

#### 📄 למאמרים ודפים:
1. **תוכן פרטי לשיתוף ממוקד**
   - מאמרים או דפי נחיתה שרוצים לשתף עם קבוצה ספציפית
   - דפי מידע פנימיים שנגישים רק בקישור ישיר

2. **תוכן ארכיוני**
   - מאמרים ישנים שרוצים לשמור אבל לא להציג
   - תוכן היסטורי שעדיין רלוונטי למי שמחפש אותו

3. **דפי נחיתה לקמפיינים**
   - דפי Landing Page שמיועדים רק לתנועה מפרסומות
   - תוכן ממוקד לקהל ספציפי

4. **תוכן בבדיקה**
   - דפים חדשים שבבדיקה אבל כבר מפורסמים
   - תוכן שצריך אישור לפני הצגה למבקרים רגילים

#### 📋 לטפסים ו-Custom Post Types:
1. **טפסים פרטיים**
   - טפסי רישום שנגישים רק דרך קישור ספציפי
   - סקרים או שאלונים לקבוצות מוגדרות

2. **תוכן מותאם אישית**
   - כל post type מותאם שצריך להיות נגיש אבל לא מוצג

### מתי **לא** להשתמש:
- ❌ תוכן שצריך להיות מוסתר לגמרי → השתמש בסטטוס "טיוטה"
- ❌ מוצרים שאזלו מהמלאי → השתמש בניהול מלאי של WooCommerce
- ❌ תוכן שנמחק → השתמש בפח האשפה
- ❌ תוכן שדורש הרשאות → השתמש בהגנת סיסמה או הרשאות משתמשים

## 🔧 איך להשתמש?

**הסטטוס זמין בכל סוגי התוכן:**
- 🛍️ מוצרים (WooCommerce)
- 📝 מאמרים (Posts)
- 📄 דפים (Pages)
- 📋 טפסים (Gravity Forms entries - אם הם post type)
- 🔧 כל post type מותאם אישית באתר

**אותו תהליך לכל סוג תוכן:**

### שינוי סטטוס של תוכן קיים:

1. **גש לעמוד עריכת התוכן**
   ```
   למוצר: מוצרים → כל המוצרים → [בחר מוצר]
   למאמר: מאמרים → כל המאמרים → [בחר מאמר]
   לדף: דפים → כל הדפים → [בחר דף]
   ```

2. **מצא את תיבת "פרסום"** בצד ימין של המסך

3. **לחץ על "ערוך" ליד סטטוס התוכן**

4. **בחר "מפורסם ומוסתר"** מהרשימה הנפתחת

5. **לחץ "עדכן"** לשמירת השינויים

### יצירת תוכן חדש עם הסטטוס:

1. **צור תוכן חדש כרגיל**
   ```
   למוצר: מוצרים → הוסף חדש
   למאמר: מאמרים → הוסף חדש
   לדף: דפים → הוסף חדש
   ```

2. **מלא את כל הפרטים הנדרשים**

3. **לפני פרסום, שנה את הסטטוס ל-"מפורסם ומוסתר"**
   - לחץ על "ערוך" ליד "סטטוס: טיוטה"
   - בחר "מפורסם ומוסתר"
   - לחץ "אישור"

4. **פרסם את התוכן**

## 🎨 תצוגה במערכת

### בטבלת התוכן (מוצרים / מאמרים / דפים):
תוכן עם הסטטוס יוצג עם תווית **"מפורסם אך נגיש בלינק ישיר בלבד"** ליד השם.

```
┌──────────────────────────────────────────────────────────────┐
│ כותרת התוכן — מפורסם אך נגיש בלינק ישיר בלבד               │
└──────────────────────────────────────────────────────────────┘
```

**דוגמאות:**
- 🛍️ מוצרים: `שם המוצר — מפורסם אך נגיש בלינק ישיר בלבד`
- 📝 מאמרים: `כותרת המאמר — מפורסם אך נגיש בלינק ישיר בלבד`
- 📄 דפים: `שם הדף — מפורסם אך נגיש בלינק ישיר בלבד`

### בעמוד עריכה:
בתיבת "פרסום" יופיע:
```
סטטוס: מפורסם אך נגיש בלינק ישיר בלבד
```

זהה לכל סוגי התוכן.

## 🔍 אינטגרציה עם Relevanssi

אם אתם משתמשים ב**Relevanssi** (תוסף חיפוש מתקדם), המערכת תטפל אוטומטית בהסתרת התוכן:

### מה קורה?
- ✅ **הסתרה אוטומטית** - תוכן עם הסטטוס לא יופיע בתוצאות חיפוש של Relevanssi
- ✅ **שני שכבות הגנה** - גם ברמת הפוסט (`relevanssi_post_ok`) וגם ברמת השאילתה (`relevanssi_modify_wp_query`)
- ✅ **ללא הגדרות נוספות** - האינטגרציה אוטומטית ועובדת מיד

### איך זה עובד?
המערכת מוסיפה שני פילטרים:
1. `relevanssi_post_ok` - מסנן פוסטים בודדים
2. `relevanssi_modify_wp_query` - מסנן את כל השאילתה

### בדיקה:
1. צור תוכן עם הסטטוס החדש
2. חפש את התוכן ב-Relevanssi
3. ✅ התוכן לא יופיע בתוצאות
4. ✅ התוכן עדיין נגיש בקישור ישיר

## 🔍 איך זה עובד מאחורי הקלפים?

### הסטטוס הטכני:
```php
post_status = 'publish-hidden'
```

**זהה לכל סוגי התוכן** - מוצרים, מאמרים, דפים וכל post type.

### התנהגות המערכת:

#### ✅ התוכן **יופיע**:
- בדף התוכן עצמו (single post/page/product)
- בממשק הניהול של WordPress
- בדוחות ובדשבורד
- בגישה ישירה דרך URL

#### ❌ התוכן **לא יופיע**:
- בדפי ארכיון (archive pages)
- בדפי קטגוריות
- בתוצאות חיפוש
- בווידג'טים ("מאמרים אחרונים", "מוצרים אחרונים" וכו')
- בלופים מותאמים אישית (WP_Query, get_posts)
- בדף הבלוג הראשי (למאמרים)
- בדף החנות (למוצרים)
- ב-Related Products (למוצרים)
- בכל תצוגת רשימה אוטומטית

## 🛠️ פתרון בעיות

### המוצר עדיין מופיע בחיפוש
**פתרון:**
1. נקה את המטמון של האתר
2. נקה את המטמון של תוסף אופטימיזציה (אם יש)
3. וודא שהסטטוס באמת `publish-hidden` ולא `publish`

### המוצר לא נגיש בקישור ישיר
**בדוק:**
1. שהמוצר לא בסטטוס "טיוטה"
2. שה-Permalink תקין
3. שאין בעיית הרשאות משתמש

### המוצר מופיע בוידג'טים
**אפשרות 1:** הוידג'ט שואב מוצרים בצורה מותאמת אישית
- צור קשר עם מפתח האתר

**אפשרות 2:** מטמון לא נוקה
- נקה את המטמון ובדוק שוב

## 🔒 אבטחה ופרטיות

### ⚠️ שים לב:
- המוצר **לא** מוגן בסיסמה
- מי שיודע את הקישור **יכול** לגשת למוצר
- המוצר **יופיע** במנועי חיפוש (Google) אם הם זחלו אותו בעבר

### למוצרים רגישים:
אם המוצר מכיל מידע רגיש:
1. השתמש בתוסף הגנה נוסף
2. שקול שימוש בסטטוס "פרטי" במקום
3. הגדר הרשאות משתמשים
